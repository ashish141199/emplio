| Path | What it holds |
|---|---|
| `backend/src` | The API (Bun and Fastify): chat, `emplio` commands, apps, automations, agents, background work. Starts at `index.ts`. |
| `backend/src/sandbox.ts` | Each person's computer, the `emplio` command and Emplio's rules. |
| `backend/src/integrations` | Apps: Composio, in-house apps (`own/`), polled triggers (`polls/`) and the app list (`catalog.ts`). |
| `backend/src/channels` | Ways to talk besides the web app. Telegram today. |
| `backend/src/db` | The Postgres schema, with migrations in `backend/drizzle`. |
| `backend/scripts` | Tools for builders, such as `openapi-actions.ts` for in-house apps. |
| `frontend/src` | The web app (Next.js and shadcn/ui). |
| `shared` | Types and helpers used by both the API and the web app. |
| `runner` | The gatekeeper: the only program that controls Docker. |
| `docker` | Dockerfiles for the four images, the Caddyfile, start scripts and the smoke test. |
| `docs` | These docs (Mintlify). |
| `.github` | CI, the contributor agreement check, issue and pull request templates. |
| `install.sh` | The one-line installer. Downloads the repo, then runs `setup.sh`. |
| `setup.sh` | Writes `.env` the first time, then downloads or builds and starts everything. |
| `docker-compose.yml` | Every service on one machine. |
| `.env.example` | The settings, with notes. See [Configuration](/self-host/configuration). |
