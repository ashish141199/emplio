If you find a security problem in Emplio, please report it privately. Don't open a public issue.

<Steps>
  <Step title="Email us">
    Write to **ashish@kulp.ai**.
  </Step>
  <Step title="Say what you found">
    Include what you found, how to reproduce it, and which version or commit you were running.
  </Step>
  <Step title="Hear back">
    We'll reply as soon as we can and keep you posted while we fix it.
  </Step>
</Steps>

<Warning>Please don't test against other people's installs or data. Your own install is fine.</Warning>

## How Emplio keeps installs safe

- Each person's computer and browsers run in their own containers and network.
- Only the small `runner` service controls Docker, and only for Emplio's own two images.
- Saved passwords and keys are encrypted with `ENCRYPTION_KEY`, and Emplio sees their names, never their values.
