When a kind of work keeps coming back, Emplio sets up an agent for it, like a Supplier Finder or an Invoice Chaser, and hands it that work from then on. You don't need to set anything up.

## How agents work

- Emplio hands a job to an agent and keeps managing it. Several can work at once.
- Each job shows in the sidebar under the chat it came from. Open it to watch or write to it. See [Chat](/guide/chat#work-in-the-background).
- Each agent keeps lessons from its past jobs, so the next one goes better.
- Emplio sets up, improves and retires agents as it works.

## See your agents

<Steps>
  <Step title="Open Team">
    Press **Team** in the sidebar, then **Agents**.
  </Step>
  <Step title="Open an agent">
    Click one to see what it does, **Skills it uses** and **What it has learned**.
  </Step>
</Steps>

The list is read-only.

## Change an agent

Tell Emplio in a chat, for example: "Have the Invoice Chaser wait 3 days before the second reminder." Only owners' and admins' chats can make or change agents.

<Tip>Don't need an agent any more? Ask Emplio to archive it. It can bring it back later.</Tip>
