Emplio is open source, so you can run the whole thing on your own computer or server. One command installs it, and the same command updates it later.

## What you get

- **Free.** The code is under the [GNU AGPL-3.0](https://github.com/emplio-app/emplio/blob/main/LICENSE). You pay only your own AI and other provider bills.
- **Your data on your machine.** Chats, memory, records and files are kept in Docker volumes on the machine you run it on.
- **The same Emplio.** Its own computer and browser, apps, memory in git, tasks, agents and automations.

## Self-hosted or Emplio Cloud

| | Self-hosted | [Emplio Cloud](https://emplio.app) |
|---|---|---|
| Cost | Free, plus your own AI and other provider bills | Paid plans |
| Computer | A container on your machine | Managed for you |
| Browser | Plain Chromium; some sites will block it | Managed, with protection against blocking |
| Links to apps Emplio starts | Not available yet | Yes |
| Keys and setup | Yours | Done for you |

<Note>Emplio runs commands and opens websites for you. Treat it like a member of staff with a computer, and never put it on the internet without HTTPS.</Note>
