Reports, quotes, sheets and pages Emplio makes, and files you attach in any chat, all land in one place. Open **Memory** in the sidebar, then **Files**.

## Find a file

- Search by name or by the words inside.
- Show **All**, **By Emplio** or **Uploaded**.
- Click a file to open it beside the list.

## Share a link

<Steps>
  <Step title="Open the file">
    Click it in the list.
  </Step>
  <Step title="Press Share">
    A link is made and copied. Anyone with the link can open the file without signing in.
  </Step>
  <Step title="Stop sharing when done">
    Press **Shared**, then **Stop sharing**. The link stops working.
  </Step>
</Steps>

The menu beside each file also has **Go to its chat**, **Download**, **Rename** and **Delete**.

<Note>You see the files from your own chats. Owners and admins see everyone's.</Note>
