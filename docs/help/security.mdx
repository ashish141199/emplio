Emplio runs commands and opens websites for you, so treat it like a member of staff with a computer. Here is what keeps that safe.

| Protection | What it means for you |
|---|---|
| Separate computers | Each person's computer and browser run in their own container and network, apart from everyone else's. |
| Encrypted passwords | Passwords and keys you save under **Passwords & keys** are stored encrypted. Emplio fills them in only on the site they were saved for, and the value is never handed to the AI. |
| Approvals | Before Emplio sends, changes or deletes anything in your apps, it asks you. Automations may only do what the owner or an admin allowed. |
| Restricted files | Money, pay, HR and owner notes go in **Restricted**, which only the owner and admins see. Tables marked **Private** are the same. |
| Roles | **Owner**, **Admin** and **Staff**. Staff can't see restricted files or change skills. Only the owner and admins set up automations. |
| Sign-in | No passwords for Emplio itself. You sign in with a code sent to your email, with limits on how many tries it gets. |
| History | Memory is kept with full history, so any change can be seen and undone. |

<Note>Recording a task with **Show Emplio how** doesn't record passwords.</Note>

## Report a security problem

Found a security problem? Email **ashish@kulp.ai** instead of opening a public issue. Say what you found, how to reproduce it, and which version you were running. Please test only on your own install.
