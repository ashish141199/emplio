# Code of conduct

Be kind and assume good intent. Disagree with ideas, never with people. No harassment, insults or discrimination of any kind, in issues, pull requests or anywhere else the project meets.

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Report anything that breaks it to **ashish@kulp.ai**. We'll keep it confidential and act on it.
